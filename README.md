This is a full-stack Employee Management System built using the MERN stack. It allows organizations to manage employee data efficiently with features like authentication, role-based access control, and CRUD operations.

   Features: 
   
🔐 User Authentication (Login/Register)
👥 Role-Based Access Control (Admin / Employee)
➕ Add Employee
✏️ Update Employee Details
❌ Delete Employee
📋 View Employee List
